# Vault密盒

一款 Android 端文件加密工具，基于 RSA + AES 混合加密方案，用非对称密钥保护文件安全。

## 功能

- **文件加密 / 解密**：通过系统文件选择器选取文件，一键加密或解密
- **RSA 密钥管理**：生成 2048 位 RSA 密钥对，支持 PEM 格式导入 / 导出（兼容 PKCS#1 与 PKCS#8）
- **混合加密**：随机 AES 密钥加密文件内容，RSA 公钥包装 AES 密钥，兼顾性能与安全性
- **AES-GCM 认证加密**：文件内容使用 AES/GCM 模式，具备完整性与防篡改能力
- **密钥复制**：加密后的 AES 密钥可一键复制到剪贴板，便于保存或传输

## 加密流程

1. 生成随机 AES 密钥，以 AES/GCM 加密文件内容
2. 使用 RSA 公钥包装该 AES 密钥
3. 输出加密文件，RSA 包装密钥单独复制保存

解密时导入 RSA 私钥（PEM），解出 AES 密钥后还原文件。

## 技术栈

| 项目 | 说明 |
| --- | --- |
| 语言 | Kotlin |
| UI | Jetpack Compose + Material 3 |
| 加密 | JCA（AES/GCM、RSA）+ BouncyCastle（PEM 解析） |
| 构建要求 | minSdk 24 / targetSdk 36 / JDK 11 |

## 构建运行

```bash
./gradlew assembleDebug
```

产物位于 `app/build/outputs/apk/debug/`，或直接用 Android Studio 打开项目运行。

## 安全提示

- 私钥请妥善保管，泄露即失去文件保密性
- 加密文件与 RSA 包装密钥需配套保存，丢失任一者将无法解密
- 项目加密逻辑仅供学习交流，未经安全审计，请勿用于高强度保密场景
